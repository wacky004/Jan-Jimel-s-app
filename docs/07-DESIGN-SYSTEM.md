## Typography

- Headings: **Playfair Display** (600/700/800) → `font-display`
- Body: **Poppins** (300–600) → default body font
- Google Fonts loaded in `frontend/index.html`

## Effects rules (from MASTER.md)

- Large section gaps (48px+), bold hover color shifts, 150–300ms transitions
- Large type (32px+ headlines), high-contrast navy/gold
- Static hero + non-pulsing CTA under `prefers-reduced-motion`
- Shadows: sm/md/lg/xl depth scale documented in MASTER.md

## Checklist applied to all UI work

- No emojis as icons — inline SVG (Lucide-style paths)
- `cursor-pointer` on clickable elements (global button rule in index.css)
- 4.5:1 minimum text contrast
- Visible gold focus rings (`:focus-visible`)
- `prefers-reduced-motion` respected (CSS kill-switch + Framer `MotionConfig` +
  3D hero static mode)
- Responsive at 375/768/1024/1440
